Help
  • Prev / Next move between questions; answers save automatically.
  • Flag marks a question to revisit; flagged questions show a flag in the Index.
  • Index lists every question as answered, unanswered or flagged.
  • Tools → Highlighter: select passage text to highlight; click a highlight to remove it.
  • Tools → Answer Eliminator: strike out choices you have ruled out.
  • Tools → Line Reader: a reading band follows your pointer (or use ↑/↓).
  • Tools → Magnifier: cycles text size.
  • Contrast changes the color scheme.
  • End Test opens the review screen before you submit.
  • Keyboard: Alt+→ next, Alt+← previous, Alt+F flag.
